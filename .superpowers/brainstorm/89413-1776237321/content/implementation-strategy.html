Implementation Strategy

How we'll transition Draupnir to the new "Cleaner Lines" aesthetic.

A

Theme-Driven Foundation (Recommended)

Update tailwind.config.ts and app.css with the new "Midnight Bloom" tokens (colors, spacing, Geist fonts). This ensures the "Overall" part of your request is handled consistently across all pages.

B

Dashboard-First Prototype

Implement the new look specifically on Dashboard/Index.tsx first using custom classes. We'll refine the look in-situ before extracting it into global theme tokens.

Recommendation: Approach A

Since you want to improve overall UI/UX, starting with the theme foundation is safer. It prevents "UI drift" and makes the Dashboard implementation cleaner by using standard Tailwind tokens like bg-background and border-border that are already wired to the new look.
